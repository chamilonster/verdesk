  • 标准 MCP

  • DOM 模式浏览器

    通过代码读取网页，不用图像。适用于允许自动化的网站。

    完整读取：24–34 毫秒

  • 不可检测浏览模式

    你平常用的浏览器，配合真实的鼠标和键盘。适用于要求严格的网站。

    navigator.webdriver = false

  • 原生 OCR

    读取屏幕上的文字，无需向智能体发送图像。

  • 截取区域

    只看屏幕上重要的部分，而不是整个屏幕。

  • 变化检测

    只发送自上次查看以来的变化，并可等待某处发生变化。

  • 操作日志与提示音

    每个操作都会被记录；提示音可选。

安装

  1. 从 GitHub Releases 下载安装程序（Verdesk_x.y.z_x64-setup.exe）。
  2. 运行它。不需要管理员权限；完成后，Verdesk 图标会出现在系统托盘中。
  3. 点击托盘图标 → 设置 → 连接 → 复制提示词，然后粘贴到智能体的终端（Claude Code、Codex、OpenCode 等）。
  4. 关闭并重新打开智能体的终端，让它加载 MCP 服务器。
