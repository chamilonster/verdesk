기능

  • 올인원

    브라우저와 데스크톱을 하나의 서버로.

  • Computer Use보다 저렴

    비전 토큰 89% 절감: 변경된 부분만 전송.

    20턴 시뮬레이션 벤치마크

  • 표준 MCP

    모든 모델. Claude Code에서 테스트됨.

  • DOM 모드 브라우저

    이미지 없이 코드로 페이지를 읽습니다. 자동화를 허용하는 사이트용.

    전체 읽기: 24–34ms

  • 탐지되지 않는 탐색 모드

    평소 쓰는 브라우저를 실제 마우스와 키보드로. 까다로운 사이트용.

    navigator.webdriver = false

  • 네이티브 OCR

    에이전트에 이미지를 보내지 않고 화면의 텍스트를 읽습니다.

  • 캡처 영역

    화면 전체가 아니라 필요한 부분만 봅니다.

  • 변경 감지

    마지막으로 본 뒤 바뀐 부분만 보내고, 무언가 바뀔 때까지 기다릴 수 있습니다.

  • 작업 로그와 알림음

    모든 작업이 기록됩니다. 알림음은 선택 사항입니다.

  • 작업 스크립팅

    PRO

    데스크톱 작업을 매크로로 녹화하고 한 번의 호출로 반복합니다.

  • 버튼 미니 캡처

    PRO

    버튼을 '요소'에 한 번 저장하면 에이전트가 찾아서 누릅니다.

  • 원격 PC도 제어

    PRO

    SSH 터널을 통해, 당신의 키로.

예시

  • 웹 포털 민원 처리
  • API가 없는 Windows 프로그램
  • 웹 페이지에서 데이터 추출
  • 직접 만든 앱 테스트
  • Windows 설정 변경
  • 데스크톱 작업 반복PRO

설치

  1. GitHub Releases에서 설치 프로그램(Verdesk_x.y.z_x64-setup.exe)을 다운로드합니다.
  2. 실행합니다. 관리자 권한이 필요 없으며, 설치가 끝나면 Verdesk 아이콘이 시스템 트레이에 표시됩니다.
  3. 트레이 아이콘 클릭 → 설정 → 연결 → 프롬프트 복사 후, 에이전트의 터미널(Claude Code, Codex, OpenCode 등)에 붙여넣습니다.
  4. 에이전트의 터미널을 닫았다가 다시 열어 MCP 서버를 불러옵니다.
