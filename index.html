Install

  1. Download the installer (Verdesk_x.y.z_x64-setup.exe) from GitHub Releases.
  2. Run it. It doesn't ask for administrator rights; when it finishes, the Verdesk icon sits in the system tray.
  3. Click the tray icon → Settings → Connection → Copy prompt, and paste it into your agent's terminal (Claude Code, Codex, OpenCode, etc.).
  4. Close and reopen your agent's terminal so it loads the MCP server.
